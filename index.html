Roadmap del Laboratorio Cloud

La sequenza pratica affrontata per ideare, automatizzare e rilasciare l'infrastruttura:

1. Pagina Web index.html

Struttura HTML statica essenziale di presentazione.

2. Versionamento Git & GitHub

Repository, commit atomici e tracciamento continuo.

3. Containerizzazione Dockerfile + Nginx

Impacchettamento in un'immagine leggera ed eseguibile ovunque.

4. Configurazione Locale Docker Compose

Avvio rapido del container e port-mapping con un solo comando.

5. Automazione CI GitHub Actions

Pipeline di convalida e controllo automatico a ogni push.

6. Pubblicazione Online GitHub Pages

Rilascio sul web accessibile pubblicamente a zero costi.

7. Cluster Locale Kubernetes

Deployment, service e verifica pratica dell'auto-healing dei pod.

8. Infra as Code Terraform

Gestione e provisioning del container come codice (IaC).
